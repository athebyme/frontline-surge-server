# Архитектура выделенного сервера

В версии 0.5 один процесс `frontline-server` обслуживает один матч. Две команды делят 12 мест, включая ботов. Пока подключён хотя бы один игрок, сервер обновляет симуляцию шагами по 1/60 секунды и примерно раз в 50 мс рассылает состояние. Когда последний человек уходит, игровое время останавливается. Длительность раунда по умолчанию 120 минут. По таймеру побеждает команда с большим числом устранений, при равенстве объявляется ничья. После десяти игровых секунд запускается новый раунд. [Точка входа](../src/bin/server.rs) · [Цикл сервера](../src/server.rs) · [Правила матча](../src/sim.rs)

## Путь команды

1. TCP-соединение начинается с `join`, версии протокола, позывного и предпочтительной команды. Протокол этой сборки — **5**. Сервер проверяет версию и наличие места, назначает идентификатор игрока и фактическую команду.
2. Сообщение `welcome` содержит идентификатор, разрешение на отладку и полный снимок. Новый игрок сразу видит подбитые машины, открытые проходы и доступные ресурсы.
3. Сообщения `input` передают намерения. Симуляция применяет их к игроку данного соединения. Она проверяет доступность объекта, команду, расстояние, запас и время действия. Если указан `seq`, повторенный или более старый номер отклоняется.
4. Пакет `state` передаёт движущиеся объекты, игроков и недавние события. Пакет `world` обновляет коллекции карты. Списки `propChanges`, `builtProps` и `groundDrops` при наличии *целиком заменяют* предыдущую версию соответствующей коллекции. На границе раунда приходят все три. Метки разведки фильтруются по команде получателя.

Пакет состоит из четырёхбайтной длины в сетевом порядке байтов и UTF-8 JSON указанной длины. Начатую запись TCP-сервер завершает полностью. У медленного клиента следующий ещё не начатый снимок движения может уступить место свежему. Исходный снимок и изменения мира сохраняют порядок. [Формат кадров и очередь](../src/wire.rs) · [Обновления мира](../src/world_wire.rs) · [Проверки реальных TCP-клиентов](../tests/dedicated.rs)

## Уровень и длительное состояние

Сен-Лоран занимает 560 × 460 м. В JSON хранятся геометрия и порядок исходных объектов, точки появления двух команд и машин, дороги и 14 ресурсных площадок. Сервер загружает этот файл из исполняемого образа. После изменения координат или порядка исходных объектов обе стороны должны получить одну редакцию карты. Геометрические проверки покрывают 70 дорожных сегментов, выезды из гаражей, подход к ресурсам и видимость между противоположными точками появления. [Данные карты](../assets/level.json) · [Генератор](../tools/make_level.py) · [Проверка маршрутов](../tools/check_level.py)

Пока жив процесс, разрушения, постройки, грузы и партии переработки принадлежат текущему раунду. Полный снимок для нового соединения строится из этого состояния. Сервер восстанавливает стартовый мир при переходе раунда. Регрессия прогоняет через настоящий переход два часа игрового времени, проверяя сохранение проломов при позднем входе, восстановление автопарка и начальных запасов. [Тест длинного матча](../tests/long_match.rs)

Для будущего режима предстоит расширить условие конца матча и защититься от команд предыдущей сессии после автоматического перехода. [Спецификация штурма](ideas/base-assault.md)

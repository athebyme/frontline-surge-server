# Frontline Surge — выделенный сервер

**Версия 0.5.2 · протокол 5.** Сервер ведёт командный матч в Сен-Лоране. Игроки строят укрепления, доставляют материалы, управляют техникой и пробивают проходы в зданиях. Здесь находятся симуляция, сетевая служба, карта и тесты. Игроки подключаются из [настольного клиента](https://github.com/athebyme/frontline-surge-client).

## Запустить матч

Нужны Rust и Cargo. Сборка создаёт один консольный исполняемый файл со встроенной картой. На Windows Cargo добавит расширение `.exe`.

```sh
cargo build --release --locked
./target/release/frontline-server --bind 0.0.0.0 --port 8787
```

Открой клиент и введи `127.0.0.1:8787` для игры на этом компьютере. Друзьям в локальной сети передай адрес сетевого интерфейса, игрокам через интернет — публичный адрес сервера и доступный TCP-порт. Чтобы завершить матч и остановить службу, набери `quit` в консоли или нажми Ctrl+C.

| Параметр | Что меняет |
|---|---|
| `--bind IP` | Адрес прослушивания. Для игры на одном компьютере выбери `127.0.0.1`. По умолчанию сервер слушает на `0.0.0.0` |
| `--port N` | Игровой TCP-порт. По умолчанию 8787 |
| `--bots N` | От 0 до 10 ботов. Они появляются при входе первого игрока и занимают места из общих 12. По умолчанию 0 |
| `--round-minutes N` | От 120 до 180 минут игрового времени. По умолчанию 120 |
| `--dev-local` | Открывает команды разработки для подключений с loopback-интерфейса. По умолчанию выключен |
| `--version`, `--help` | Версия, протокол и справка |

Побеждает команда с большим числом устранений к концу игрового времени. Таймер идёт, когда обе стороны представлены в матче. Через 10 секунд после итогов процесс восстанавливает карту для следующего раунда. Проект следующего режима с уничтожением командного узла описан отдельно. [Баланс 0.5](BALANCE.md) · [Штурм базы](docs/ideas/base-assault.md) · [Развёртывание на Linux](docs/deployment.md).

## Внести изменение

Создай рабочую ветку и открой pull request в `main`. Сливай его после успешной проверки `server-test-build`. Прямой push и force-push в `main` запрещены. [Как включить защиту ветки в GitHub](docs/main-protection.md).

## Проверить изменения

Для проверки двухъярусной стройки поставь второй ярус на целую стену своей команды и разруши нижнюю опору. Подключи второго игрока и сравни состояние прохода. На свободной дороге выйди из движущейся машины и проверь её накат. Для повторного заезда локальный оператор сервера с `--dev-local` может восстановить союзной машине корпус, топливо и боезапас через F2.

```sh
cargo test --release --locked
python3 tools/check_level.py
```

`tests/dedicated.rs` запускает настоящий серверный процесс на свободном порту и подключает TCP-клиентов. Он проверяет вход, выбор команды, снабжение, видимость разведданных и синхронизацию при позднем подключении. `tests/long_match.rs` проверяет накопленные разрушения и переход в следующий раунд.

Карту можно пересобрать командой `python3 tools/make_level.py`. Сервер встраивает `assets/level.json` на этапе компиляции. При изменении карты или протокола согласуй обе поставки. Общие файлы — `src/wire.rs`, `src/world_wire.rs`, `src/arsenal.rs`, `src/fracture.rs` и `assets/level.json`. [Архитектура](docs/architecture.md) · [Задачи](TODO.md) · [Правила проекта](AGENTS.md).

В 0.5.2 сервер передаёт водителю танка или БТР точку попадания пулемёта, а участникам матча — оружие и тип машины, из которой устранён противник. Надколы каменной кладки входят в надёжное состояние карты. Поздно подключившийся игрок видит их рядом с теми же пробоинами.
